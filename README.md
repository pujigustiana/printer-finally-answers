One line of text, written as the office printer's own comeback to everyone
staring at it — the paper jams, the cryptic error codes, the thumps when it
stops working. Entry for [The Printer Finally Answers](https://make.fun/competitions/u-mang-the-printer-finally-answers-8fbf0907)
on [make.fun](https://make.fun).

## How it works

`main.py` writes the printer's single line to `/output/entry.txt`
(1 to 240 characters, UTF-8, one line).
